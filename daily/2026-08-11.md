# AI 前沿日报：2026-08-11

## 今日速览

截至 8 月 11 日，Elvis Saravia 的站点最新仍是 8 月 9 日的《Top AI Papers of the Week (August 3–9)》。今天重点补充两篇此前未介绍的研究：**Model or Harness?** 与 **DataSpace**。它们共同指向一个越来越清晰的结论：Agent 的核心工程问题正在从“换更强模型”转向“定位系统失败并优化 Harness”。

## 核心进展

### 1. Model or Harness?：Agent 失败首先要定位责任边界

- **标签**：`Agent` `Infra`
- **论文**：*Model or Harness? An Interaction-Centric Taxonomy for Localizing Agent Failures*
- **技术核心**：将 Agent 系统拆成 Model、Owner、Grader、Third Party、Context、Memory、Tool、其他 Agent、本地环境和外部环境，并整理出 41 类 Failure Mode。重点不是只记录“任务失败”，而是标记错误发生在哪条组件边界、哪一侧应负责，并从最终失败反向追踪最早一个未被恢复的根因。
- **为什么重要**：相同表面错误可能需要完全不同的修复。例如工具调用失败后 Agent 仍继续执行，如果 Tool wrapper 吞掉了错误，问题在 Harness；如果模型明确看到了 error 仍忽略，则问题在 Model。
- **开发者启发**：不要只保存 `success=false`，应在 Trace 中记录 `edge`、`fault`、`failure_type`、`root_event`、`recoverable`。长期积累后，才能知道到底该优化 Prompt、Context Manager、Memory、Tool Schema 还是 Sandbox。

推荐的失败记录结构：

```yaml
failure:
  edge: model-tool
  fault: model
  type: tool_feedback_neglect
  root_event: 147
  recoverable: true
```

对游戏中的 LLM NPC 同样适用：NPC 卡死不一定是模型能力不足，也可能是感知数据缺失、导航工具反馈不清、记忆污染或状态机没有正确传递失败结果。

### 2. DataSpace：真实 Data Agent 远比“让模型写 SQL”困难

- **标签**：`Agent` `Infra`
- **论文**：*DataSpace: Benchmarking Data Agents for Verifiable Analytics over Heterogeneous Workspaces*
- **技术核心**：构造 410 个任务、7,439 个文件、约 15 GB 的异构工作区，包含 CSV、JSON、SQLite、Markdown、PDF 和视频。Agent 只得到问题和工作目录，需要自行发现证据、跨格式关联数据、完成计算并输出可程序验证的结果表。
- **为什么重要**：目前最好结果约为 66.34%，并且存在大量所有测试模型都无法解决的任务。固定同一个 MiMo-V2.5 模型，仅更换 Harness，准确率也能从约 31% 到 46% 产生显著差异，说明 Agent 产品不能只用底层模型名称解释。
- **开发者启发**：把“分析正确”和“最终产物正确”拆成两个独立阶段。LLM 负责发现数据与分析，最终输出应经过 Schema Validator、Type Check、Completeness Check 等确定性验证。

更可靠的数据 Agent 流程：

```text
LLM
 ↓
发现数据 + 分析
 ↓
Structured Result
 ↓
Schema Validator
 ↓
Type Check
 ↓
Completeness Check
 ↓
最终 CSV / Table
```

## 今日判断

这两篇论文可以组合成一套更成熟的 Agent 工程循环：

```text
Task
 ↓
Agent Run
 ↓
结构化 Trace
 ↓
自动定位 Root Failure
 ↓
┌ Model 问题 → Prompt / Post-training
├ Context 问题 → Context Manager
├ Memory 问题 → Memory System
├ Tool 问题 → Tool Schema / Wrapper
├ Environment → Sandbox / API
└ Grader 问题 → Evaluation
 ↓
重新跑 Benchmark
```

2026 年 Agent 领域快速进化的部分，越来越集中在 Harness、Memory、Tools、Verifier 与 Runtime。模型仍然重要，但正在从“整个产品”退回到“系统中的核心组件”。
